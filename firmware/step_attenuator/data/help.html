Device Overview

The Digital Attenuator is a programmable RF attenuator designed for test and measurement applications. It provides precise attenuation control from 0 to 127 dB in 1 dB steps.

Technical Specifications

Attenuation Range
0 - 127 dB
Step Size
1 dB
Control Interfaces
Web, SCPI, Telnet, Rotary Encoder
Network Connectivity
WiFi 802.11 b/g/n
Display
OLED with real-time value
Manufacturer
Quirky Solutions by SQ9NJE

Web Interface Features

Main Controls

  • Current Value Display: Shows the current attenuation value in real-time
  • Quick Presets: Buttons for common values (0, 10, 20, 30, 40, 50, 60, 80 dB)
  • Fine Control: +1/-1 dB adjustment buttons
  • Custom Value: Direct input field for any value from 0-127 dB

Keyboard Shortcuts

  • Ctrl + ↑: Increase attenuation by 1 dB
  • Ctrl + ↓: Decrease attenuation by 1 dB
  • Ctrl + 0: Reset to 0 dB attenuation

Status Information

  • Connection Status: WiFi connection state
  • Network: Connected SSID
  • IP Address: Current device IP
  • Last Update: Timestamp of last status refresh

System Configuration

  • WiFi Reset: Reset network settings and restart in AP mode
  • Access Point Mode: SSID "StepAttenuator", Password "configure"

SCPI Command Reference

The device implements SCPI (Standard Commands for Programmable Instruments) for remote control. All commands are case-insensitive and support standard SCPI abbreviations.

IEEE 488.2 Mandatory Commands

Command Description Response
*IDN? Identification query SQ9NJE,Digital-Attenuator,0-127dB,v1.0
*RST Reset device to default state Sets attenuation to 0 dB
*TST? Self-test query 0 (pass) or non-zero (fail)
*OPC Operation complete Sets operation complete flag
*OPC? Operation complete query 1 (complete) or 0 (in progress)
*CLS Clear status Clears error queue and status

System Commands

Command Description Response
SYSTem:ERRor? Read error from queue Error code and message
SYSTem:VERSion? SCPI version query 1999.0

Network/WiFi Commands

Command Description Parameters Response
SYSTem:NETwork:STATus? Query network connection status None CONNECTED, CONNECTING, DISCONNECTED, ACCESS_POINT, ERROR, UNKNOWN
SYSTem:NETwork:IP? Query device IP address None IP address or 0.0.0.0 if not connected
SYSTem:NETwork:SSID? Query connected network name None Network SSID or "Not Connected"
SYSTem:NETwork:INFO? Query comprehensive network info None Connection details (semicolon separated)
SYSTem:WIFI:RESet Reset WiFi settings and restart None Confirmation message
SYSTem:WIFI:CONFigure Configure WiFi network [SSID] [PASSWORD] or none for AP mode Configuration status

Attenuation Control Commands

Command Abbreviations

SCPI supports standard abbreviations. Capital letters show the minimum abbreviation:

  • SYSTem can be abbreviated as SYST
  • NETwork can be abbreviated as NETW
  • STATus can be abbreviated as STAT
  • CONFigure can be abbreviated as CONF
  • ATTenuator can be abbreviated as ATT
  • VALue can be abbreviated as VAL
  • INCrement can be abbreviated as INC
  • DECrement can be abbreviated as DEC
  • MINimum can be abbreviated as MIN
  • MAXimum can be abbreviated as MAX

Python Script Example

Python automation example:
import socket

def send_scpi(ip, command):
    sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    sock.connect((ip, 5025))
    sock.send(f"{command}\n".encode())
    if command.endswith('?'):
        response = sock.recv(1024).decode().strip()
        sock.close()
        return response
    sock.close()

# Check network status
status = send_scpi("192.168.1.100", "SYST:NETW:STAT?")
print(f"Network status: {status}")

# Set attenuation to 25 dB
send_scpi("192.168.1.100", "ATT:VAL 25")

# Read current value
value = send_scpi("192.168.1.100", "ATT:VAL?")
print(f"Current attenuation: {value} dB")

Troubleshooting

Connection Issues

  • Cannot connect to web interface:
    • Check device IP address on OLED display
    • Ensure device and computer are on same network
    • Try accessing via IP address instead of hostname
    • Use SYST:NETW:STAT? to check connection status via SCPI
  • WiFi connection failed:
    • Reset WiFi settings using the web interface or SYST:WIFI:RES
    • Device will create "StepAttenuator" access point
    • Connect to AP and reconfigure network settings
    • Use SYST:WIFI:CONF SSID PASSWORD for direct configuration

SCPI Command Issues

  • Command not recognized:
    • Check command syntax and abbreviations
    • Ensure proper termination (line feed or carriage return)
    • Commands are case-insensitive
  • Parameter out of range:
    • Attenuation range is 0-127 dB
    • Use SYST:ERR? to read error details
  • Network commands not working:
    • Ensure device firmware supports network commands
    • Check WiFi connection status first with SYST:NETW:STAT?
    • WiFi configuration may take up to 30 seconds

Error Codes

Code Description Solution
-109 Missing parameter Provide required parameter value
-224 Illegal parameter value Check parameter range (0-127 dB)
-350 Queue overflow WiFi connection failed or other system error
0 No error Normal operation

Factory Reset

To perform a complete factory reset:

  1. Use the "Reset WiFi Configuration" button in the web interface
  2. Device will restart and create access point "StepAttenuator"
  3. Connect to the access point (password: "configure")
  4. Navigate to 192.168.4.1 to reconfigure network settings
